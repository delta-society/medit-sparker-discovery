# DEL-474 PDF 디자인 보완 검증

상태: 검증된 로컬 보완본 확정. 커밋·푸시·운영 배포와 네이티브 Windows/macOS 시험 완료를 뜻하지 않는다.

## 목표와 경계

검토 요약/상세/근거 위계, 연결된 업무 도식, 필드별 읽기 리듬, 비교 구조와 페이지별 맥락을 보완한다. 기존 확정 JSON/Markdown의 바이트와 의미를 보존하고, 참가자 추가 설치를 요구하지 않는다. PDF의 변환 힌트는 canonical 표시문과 공백 정규화 후 대응하는 경우에만 적용한다.

‘A4당 N문자·N청크’를 과학적 상한으로 도입하지 않았다. 서로 참조해야 하는 정보를 가까이 두는 방향의 근거는 [Chandler & Sweller, 1992](https://doi.org/10.1111/j.2044-8279.1992.tb01017.x)에서 확인했지만 한국어 기획서의 배치 효과를 직접 검증한 연구는 아니다. [Cowan, 2001](https://pubmed.ncbi.nlm.nih.gov/11515286/?dopt=Abstract)의 단기기억 용량을 페이지 요소 수 제한으로 사용하지 않는다. 본 검증은 사용성 실험이 아닌 코드·출력·독립 리뷰다.

초기 리뷰의 ‘특정 제목 간격이 붕괴한다’는 주장은 실제 PDF 좌표가 이를 뒷받침하지 않아 철회했다. 이미지 확대 배율의 인상을 코드 결함으로 확정하지 않았다.

## 시험 결과

- `SPARKER_PDF_TEST_BROWSER=<Chrome> python3 -m unittest discover -s plugin/tests -q`: **100개 모두 통과, 제외 없음**.
- PDF 전용 시험: **13개 통과**. 원본 해시 보존, 표시문 대응 필드 매핑, 값 안 구분자/줄바꿈, 불일치 fallback, linked 목표/연결 확보 작업, 숨은 legacy 자료 배제, 긴 값의 전체 토큰 순서, 18단계 연속성, 브라우저 초기 탭 준비 경쟁 포함.
- `python3 -m unittest discover -s examples/germany-ar -q`: **12개 통과**.
- `git diff --check`: 통과.
- 실제 실행 환경: Linux Chrome/151.0.7922.34. Python 표준 라이브러리 런타임과 사전 번들 자산 사용.
- 7종·49페이지를 전장 렌더로 확인. pdftotext bbox 기반 페이지 경계 밖 글자 0건. 이 기하 검사만으로 가독성을 판정하지 않고 이미지/독립 리뷰와 함께 사용했다.

## 로컬 산출물

검토 PDF와 페이지 이미지/기하 검사 결과는 저장소에서 제외된 `.sparker-discovery/pdf-design-final/`에 있다. `plugin-verified.zip`은 현재 런타임을 담은 명시 목록 29파일, 4,691,237바이트다. SHA-256: `33a7956329db9b22ceb4d6381fda5dc20519e146dc228628c1e20ff5a0b4dbf3`. 추출한 패키지에서 한글·공백 경로로 실제 finalize 자동 PDF와 같은 리비전 재사용 및 원본 불변을 확인했다. 결과는 `package-check.json`에 기록했다.

재현: `SPARKER_PDF_BROWSER=<browser> python3 scripts/verify-pdf-export.py --extended --output <새 폴더>`. Poppler/Pillow는 개발 검증에만 사용하며 참가자 패키지에 포함하지 않는다.

## 남은 범위

Windows/macOS 네이티브 실기기, 실제 참가자 설치·조직 정책 환경, 참가자 읽기 과제의 정답률/탐색 시간/페이지 왕복 측정, Camp PDF 제출은 별도다. DEL-474는 이 네이티브 검증을 구분하기 위해 In Progress로 유지한다. 이번 확정은 로컬 PDF 디자인 보완과 명시한 검증 범위에 한정한다.
